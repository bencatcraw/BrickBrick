# BrickBrick
An open source video game that can be played in the browser.

## Backstory
This project was originally made in a few hours after my girlfriend complained about the unskippable ads within her mobile game. It was then built to github pages, for ease of use and no hosting fees. The current version can be played [here](https://bencatcraw.github.io/BrickBrick/).

## Project Setup
BrickBrick is made in Unity, and requires version 6000.0.35f1. While it may run on other versions, This one is reccommended for compatibility.

Upon opening the project in Unity, you will find all objects organized into folders. Most notably, the scripts, pieces, and scenes folders which will give you an idea on how the game works.
