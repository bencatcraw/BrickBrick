# Contribution

## Bug Reports
Bug reports can be submitted through the issues tab using the bug report issue template. Be sure to describe the bug in depth and provide instructions on how to reproduce it if possible.

## Feature Requests
Like bug reports, feature requests can be submitted through the issues tab using the feature request template. Ensure any features requested have not already been added or requested in the past.

## Environment Setup
Unity 6000.0.35f1 can be installed through [Unity Hub](https://unity.com/download) or through [here](https://unity.com/releases/editor/whats-new/6000.0.35f1).

Upon cloning and launching the project, it is reccomended you run the application in smartphone simulator mode, as it was meant to be displayed on a mobile device.
Documentation for simulation can be found [here](https://docs.unity3d.com/2022.2/Documentation/Manual/device-simulator.html).

## Contact
All contact will be managed through the issues page.
